# DMC PMO Visual Theme Plan

**Direction:** Brand Modern (C) navigation + pastel interiors, Studio (B) people/icons, DMC website color language  
**Reject:** Cream/gold Accelo look, neon Monday brights, black buttons, serif titles

## Palette (muted steel / slate)

| Token | Hex | Use |
| --- | --- | --- |
| Ink | `#243447` | Body text (soft charcoal, not pure black) |
| Steel | `#3D5A73` | Primary actions, active nav |
| Steel deep | `#2F4558` | Sidebar base |
| Steel soft | `#6B8AAB` | Progress, links accent |
| Canvas | `#FFFFFF` | Page background |
| Soft well | `#F3F6F9` | Hover rows, search, chips wells |
| Surface | `#FFFFFF` | Cards, tables |
| Border | `#D5DEE8` | Hairlines |
| Muted | `#6B7C8F` | Secondary text |
| Success | `#5B8C7A` / bg `#E6F0EC` | Soft green pills |
| Warning | `#B8955A` / bg `#F6F0E4` | Soft amber pills |
| Danger | `#B56B6B` / bg `#F6EAEA` | Soft rose pills |
| Info | `#5B7C99` / bg `#E8EEF4` | Soft blue pills |

No decorative page gradients. Soft opacity transitions only. Primary buttons use steel, never black.

## Typography

- Single clean sans: **Manrope** (UI + titles)
- Remove Fraunces / serif
- Page title: 1.65rem, weight 650, tight tracking
- Comfortable spacing: content 32/28, table cells 14/16

## Shell

- Sidebar: solid muted steel, soft active pill (lighter steel wash)
- Topbar: white, soft border, circular icon buttons
- Thin scrollbars (6px)
- Avatars: real portrait photos (pravatar seeded by name) with initials fallback

## Schedule / Gantt

Soft flat status fills (not neon):

- Todo `#6B8FB5`
- Working `#D4A574`
- Review `#8B8FB8`
- Done `#7BA891`
- Milestone `#7A8BA3`
